# Phone Codex

在手机浏览器里访问 Windows 上的 Codex，并在手机和电脑之间传文件。界面包含最近会话、对话区和共享文件页，适配手机竖屏和桌面。

## 在 Windows 上启动

1. 用运行 Codex 的 Windows 账户打开 PowerShell。确认 Python 3.12 或更新版可用，且 `codex app-server --help` 能运行。使用默认临时 HTTPS 证书还需要 OpenSSL，Git for Windows 通常自带。
2. 将 Windows 连接到手机热点。运行 `ipconfig`，找到连接热点的 Wi-Fi 网卡对应的 IPv4 地址。
3. 在本项目目录运行以下命令，把 IP 换成电脑的热点 IPv4。全盘模式会列出当前账户可见的盘符，并使用当前账户的 Windows 文件权限。

   ```cmd
   python .\server.py --ip 192.168.43.100 --all-drives
   ```

   只开放指定文件夹时，改用 `--root "D:\code"`。

   启动时加 `--sync-desktop-projects`，可在桌面 Codex 完全退出后自动登记手机新建的项目。请保持 Phone Codex 服务运行，退出桌面后等几秒再打开。旧项目可用 `--sync-existing-project "D:\code\项目目录"` 指定，此参数可重复。此功能会先备份桌面索引，再登记项目和未归组的会话。

4. 用开热点的手机打开终端显示的 HTTPS 地址。确认地址和证书，再输入当前 Windows 账户的登录密码。如果手机浏览器提示证书未受信任，只有在能核对服务终端打印的 SHA-256 指纹时才继续。也可以用 `--cert` 和 `--key` 提供手机已信任、包含该热点 IP 的 PEM 证书及私钥。
5. 保持启动窗口开启。服务只监听指定 IPv4，并只接收该网卡所在子网的客户端连接。按 `Ctrl+C` 停止服务，重启后需要重新登录。

## 手机端

- **Codex** 侧栏显示桌面 Codex 保存的本机项目，并按项目归类会话。点项目路径可浏览它的文件，点「归档」可查看归档会话。可在文件页点「在此启动 Codex」，在当前目录创建会话。继续已有会话会使用原项目目录。限定目录模式只能在共享目录内启动或继续会话。正在桌面运行的任务仍由桌面客户端控制。
- **文件** 支持逐级浏览、按名称搜索当前目录、新建文件夹、改名、删除、上传和下载。全盘模式从「此电脑」进入各盘符。系统权限保护的目录、占用中的文件和链接或重解析点可能无法操作。上传单个文件上限为 512 MB，遇到同名文件会保留已有文件。全盘模式下删除的项目移入原父目录的 `.phonecodex-trash`，限定目录模式则移入共享根目录的同名文件夹。
- **微信** 支持通过手机系统分享面板选择微信，取决于浏览器、证书信任状态、文件类型和系统安装的应用。若系统未提供微信或网页不支持直接分享，请先下载文件，再通过手机文件管理器或微信的文件入口发送。

## 连接排查

- **打不开页面**：检查 IP、端口和 Windows 防火墙。若需要入站规则，仅给 Python 或指定 TCP 端口添加规则，并把范围限制在热点网卡及启动时打印的热点网段。全盘模式只在你信任的局域网启用，请勿配置端口转发或公网隧道。部分手机系统会阻止热点主机访问连接热点的设备，这种情况下可让手机和电脑连接同一个 Wi-Fi 后按新 IP 启动。
- **密码不通过**：填写 Windows 账户实际密码。Windows Hello PIN、指纹和人脸无法用于此登录流程。若当前是域账户或 Microsoft 账户，可用 `--account "DOMAIN\用户名"` 或 `--account "MicrosoftAccount\邮箱"` 指定账户。纯无密码账户无法通过此流程。
- **Codex 不显示会话**：从已登录 Codex 的同一 Windows 账户启动服务。若 `codex` 不在 PATH，使用 `--codex` 指定 `codex.exe` 的完整路径。Codex 请求仍需要电脑能访问已配置的模型服务。
